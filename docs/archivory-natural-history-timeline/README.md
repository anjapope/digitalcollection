# ArchIvory Natural History Proboscidean Timeline

A dependency-light custom timeline module for the Natural History room.

The package contains:
- HTML include
- custom CSS
- JavaScript state engine
- curator-editable JSON data
- Copilot implementation instructions
- instructions for preserving the current CollectionBuilder timeline separately

The new timeline is designed around state:
time/era → interpretation → species/groups → map state → question.

The included historical/scientific copy is an implementation scaffold and should be curator-reviewed before final publication.
