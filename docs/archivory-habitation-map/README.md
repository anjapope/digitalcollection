# ArchIvory Embedded Habitation Map

This package adds an embedded MapLibre-based habitation/evidence map to the existing Proboscidean Timeline.

The map is not a separate page. It is designed to occupy the lower workspace of the timeline while the timeline rail remains visible.

Core interaction:

timeline state → map state → evidence/reconstruction/network layers

Display modes:
- Evidence
- Reconstruction
- Combined

The included GeoJSON is intentionally placeholder-only. It exists to verify interaction and state transitions, not to serve as final historical or paleontological geography.
