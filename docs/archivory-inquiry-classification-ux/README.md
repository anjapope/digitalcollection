# ArchIvory Inquiry Classification UX

Visitor-facing implementation of the Relevance × Answerability framework.

Displays:
- 2×2 response-bin matrix
- relevance score/class/reason
- answerability score/class/reason
- originality score/class/reason

Originality is kept separate from the quadrant and framed as Foundational, Developing, or Generative.

The interface is intended as an epistemic diagnostic, not a grade.
